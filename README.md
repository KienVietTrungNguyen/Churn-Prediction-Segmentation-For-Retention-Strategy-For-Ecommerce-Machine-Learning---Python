## 📌 Project Overview

Customer churn is one of the most important problems in e-commerce because losing existing customers can directly reduce revenue and Customer Lifetime Value (CLV).

This project focuses on predicting and analyzing customer churn using Machine Learning. It also explores customer segmentation to support more personalized retention strategies.

The main goals of this project are to:

- Identify key behaviors and patterns of churned customers.
- Build a machine learning model to predict customer churn.
- Analyze important churn drivers.
- Segment churned customers for targeted retention campaigns.
- Provide business recommendations to reduce churn.

---

## 🎯 Business Questions

This project aims to answer the following questions:

- What factors contribute to customer churn in e-commerce?
- How can we predict customers who are likely to churn?
- Which machine learning model performs best for churn prediction?
- How can churned customers be segmented for personalized promotions?
- What retention strategies can be recommended based on the analysis?
